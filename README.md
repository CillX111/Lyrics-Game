# Line by Line

**Errate den Song anhand seines Textes – je schneller, desto mehr Punkte.**

Ein Multiplayer-Partyspiel für den Browser. Reihum wählt jemand einen Song und tippt ein paar Zeilen aus dem Songtext ein. Die Zeilen erscheinen nacheinander, und alle anderen raten so schnell wie möglich den Titel.

## So wird gespielt

1. `index.html` öffnen, Namen eingeben, **Neues Spiel** erstellen
2. Den Einladungslink an deine Freunde schicken (mindestens 2 Spieler)
3. Wer dran ist, wählt einen Song und gibt Textzeilen ein
4. Die Uhr startet mit der ersten Zeile – wer zuerst richtig rät, holt die meisten Punkte
5. Nach allen Runden gewinnt, wer am meisten Punkte hat

Kleine Tippfehler beim Raten werden verziehen.

## Technik

- Eine einzige HTML-Datei, keine Installation
- Die Spieler verbinden sich über [ntfy.sh](https://ntfy.sh) – kein eigener Server nötig
